Welcome to FirstProject. This repository contains a modern, responsive “Under Construction” landing page intended to serve as a temporary company website while the full product is being developed.

Project Overview

The page provides visitors with a polished holding screen that communicates that a new experience is coming soon. It includes:

A responsive layout for desktop, tablet, and mobile devices

A modern dark visual style with high-contrast accent colors

Subtle animation with reduced-motion accessibility support

A contact link for visitors who want project updates

Dynamic copyright-year display in the PHP version

Main Files

File

Purpose

index.php

Standalone PHP version of the under-construction page

app/page.tsx

Main page for the Vinext application

app/globals.css

Shared page styling and responsive design

app/layout.tsx

Page metadata and application layout

Running the PHP Version

Place the project on a web server with PHP enabled, then open index.php in a browser. For local development, run the following command if PHP is installed:

php -S localhost:8000

Then visit http://localhost:8000.

Running the Application Version

Requirements:

Node.js 22.13 or newer

npm

Install dependencies and start the development server:

npm install
npm run dev

Create a production build with:

npm run build

Customization

Before publishing the page, update the following placeholders:

Replace New Things Studio with the company or product name.

Replace hello@example.com in index.php and app/page.tsx with the correct contact email.

Adjust the introduction and status text to match the project timeline.

Update the page title and description in app/layout.tsx if required.

Note to the Team

Please keep this page lightweight and focused while the main website is under development. Test all content changes on both desktop and mobile screen sizes before publishing.
